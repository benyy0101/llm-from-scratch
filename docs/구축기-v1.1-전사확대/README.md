# 폐쇄망 LLM 구축기 v1.1 — 전사 확대

> v1.0: [폐쇄망 LLM 구축기](../구축기-v1.0/README.md) (EP01~18) · 이 폴더는 v1.0을 대체하지 않는 **별도 추가 묶음**입니다.

[EP18. 시리즈 총정리 & 운영 회고](../구축기-v1.0/EP18-시리즈-총정리-운영-회고.md)의 마지막 문단, 기억하시나요.

> "전사 확대 얘기가 슬슬 나오고 있어요. 그렇게 되면 V100 3장으로는 확실히 부족할 거고... 그때는 또 새로운 삽질이 있을 텐데, 그건 그때 가서 또 적어볼게요."

그 "그때"가 왔습니다. A저축은행 상품기획팀·개발팀 1차 배포(EP02~18) 이후, 정보보호위원회가 정식으로 **전사 확대 심의**에 들어가면서 새로운 요구사항 네 갈래가 생겼어요. 이 폴더는 그 네 갈래를 v1.0과 같은 형식(가상 시나리오 + 실제 삽질 서술 + 출처)으로 이어 쓴 것입니다.

## 왜 별도 폴더인가

EP18에서 시리즈를 한 번 정식으로 마무리했었죠(`docs/구축기-v1.0/README.md`의 목차는 EP18까지로 고정해뒀습니다). 이 폴더는 그 마무리를 무르지 않고, "그 이후 이야기"를 별도 시즌으로 붙인 것입니다. vault 개념 노트도 이 시즌에서 나온 새 개념들은 기존 MOC.md 목차를 건드리지 않고 `vault/concepts/`·`vault/engines/`에 파일만 추가했습니다.

## 가상 시나리오 갱신

v1.0과 같은 "A저축은행" 시나리오를 그대로 씁니다. 달라진 조건만 적어두면:

| 항목 | v1.0 (EP02 기준) | v1.1 |
|---|---|---|
| 대상 사용자 | 상품기획팀 40명 + 개발팀 25명 | 전사 확대 대상 약 300명 예상 (1차 확대, 전 부서는 아님) |
| GPU | V100 32GB × 3장, 전량 LLM 서빙(TP=3) | 같은 3장, 배치를 재설계 (EP21) |
| 심사 주체 | 정보보호팀 실무 승인 (EP08 rootful 예외 등) | 정보보호위원회 정식 심의 + 컴플라이언스팀 합류 |
