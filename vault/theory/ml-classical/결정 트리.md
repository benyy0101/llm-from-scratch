# 결정 트리

"이 특성이 X보다 큰가?" 같은 예/아니오 질문을 반복해서 데이터를 점점 작은 영역으로 쪼개 나가는 모델입니다. 예를 들어 고양이 6마리·개 4마리가 섞인 노드의 지니 불순도는 `1 - (0.6² + 0.4²) = 0.48`인데, 트리는 매 분기마다 "이 질문으로 나누면 자식 노드들의 불순도가 부모보다 얼마나 줄어드는가"(정보 이득)를 계산해 가장 많이 줄여주는 질문을 탐욕적으로 고릅니다. 장점은 사람이 그대로 따라 읽을 수 있는 규칙이 나온다는 것이고, 단점은 트리 하나만으로는 훈련 데이터의 노이즈까지 외워버리기 쉬워([[편향-분산 트레이드오프]] 관점에서 분산이 높음) 랜덤 포레스트처럼 여러 트리를 [[앙상블]]로 묶어 쓰는 경우가 많다는 점입니다.

## 관련
- [[앙상블]] — 트리 여러 개를 묶어 분산을 줄이는 방법(랜덤 포레스트·부스팅)
- [[편향-분산 트레이드오프]] — 트리 깊이가 조절하는 대상
- [[KNN]] · [[SVM]] — 같은 분류 문제를 다른 방식으로 푸는 대안
