# 로지스틱 회귀

이름과 달리 회귀가 아니라 분류 알고리즘입니다. [[선형 회귀]]와 똑같이 `z = wx + b`를 계산하지만, 그 결과를 그대로 쓰지 않고 시그모이드 함수에 통과시켜 0~1 사이의 확률로 바꿉니다.

```
sigmoid(z) = 1 / (1 + e^(-z))
```

z가 아주 크면 1에 가까워지고, 아주 작으면(큰 음수) 0에 가까워지고, z=0이면 정확히 0.5가 됩니다. 이 확률이 0.5 이상이면 클래스 1, 미만이면 클래스 0으로 판정합니다 — 즉 `wx+b = 0`인 지점이 두 클래스를 가르는 결정 경계이고, 이 경계는 항상 직선(또는 초평면)입니다. 곡선 경계가 필요하면 [[선형 회귀]]의 다항식 특성처럼 비선형 특성을 추가해야 합니다.

## 왜 MSE가 아니라 교차 엔트로피를 쓰는가

선형 회귀의 MSE를 시그모이드 출력에 그대로 적용하면 비용함수 곡면이 울퉁불퉁해져(비볼록) 경사하강법이 잘못된 골짜기에 갇힐 수 있습니다. 그래서 로지스틱 회귀는 이진 교차 엔트로피를 씁니다.

```
Loss = -(1/n) Σ [ y·log(p) + (1-y)·log(1-p) ]
```

정답(y=1)인데 모델이 자신 있게 틀리면(p≈0) `log(p)`가 마이너스 무한대로 발산해 손실이 폭발적으로 커지고, 맞히면(p≈1) 손실이 거의 0이 됩니다. 이 함수는 볼록(convex)이라 유일한 전역 최솟값을 향해 안정적으로 내려갈 수 있고, 신기하게도 그래디언트 수식은 선형 회귀와 형태가 똑같습니다 — `∂L/∂w = (1/n)Σ(p-y)x`. 차이는 오직 p가 `wx+b`인지 `sigmoid(wx+b)`인지뿐입니다.

세 개 이상의 클래스를 다뤄야 하면 시그모이드 대신 소프트맥스로 확장합니다. `softmax(zᵢ) = e^zᵢ / Σⱼe^zⱼ` — 모든 클래스의 점수를 합이 1인 확률 분포로 바꾸는 방식으로, GPT 계열 모델이 다음 토큰을 고를 때 쓰는 것과 같은 함수입니다.

## 정밀도·재현율과의 관계

분류기의 출력은 확률이므로, 기본 임계값 0.5를 어디로 옮기느냐에 따라 정밀도와 재현율이 반대로 움직입니다 — 임계값을 낮추면(예: 0.3) 양성으로 판정하는 경우가 늘어 재현율은 오르고 정밀도는 떨어집니다. 이 트레이드오프를 정식으로 다루는 곳이 [[모델 평가]]이고, 애초에 왜 데이터가 한쪽으로 쏠려 있으면 정확도만으로는 안 되는지는 [[불균형 데이터]]에서 이어집니다.
