# ML 파이프라인

전처리부터 예측까지 모든 단계를 하나의 재현 가능한 객체로 묶은 것으로, "제품은 모델이 아니라 파이프라인이다"라는 말이 이 개념의 핵심입니다. 전처리기(스케일러, 인코더)와 모델을 파이프라인 하나로 묶어두면, 테스트 데이터의 통계값이 훈련 과정에 몰래 섞여 들어가는 데이터 누수(예: 전체 데이터로 스케일러를 학습시킨 뒤 나눠버리는 실수)를 원천적으로 막을 수 있고, 훈련 때와 추론 때 정확히 같은 변환이 적용되는 것도 보장됩니다. sklearn의 `Pipeline`이 대표적인 구현으로, `fit()`을 호출하면 마지막 단계 전까지는 훈련 데이터에서만 통계를 계산하고, `predict()`를 호출하면 그 통계를 그대로 재사용할 뿐 다시 계산하지 않아 누수가 구조적으로 불가능해집니다.
