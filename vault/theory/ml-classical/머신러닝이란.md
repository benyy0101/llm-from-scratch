# 머신러닝이란

규칙을 사람이 직접 코드로 적는 대신, 데이터에서 규칙 자체를 찾아내게 하는 방법입니다. 스팸 필터를 예로 들면, 전통적 방식은 "제목에 '무료'가 들어가면 스팸"처럼 규칙을 하나하나 손으로 작성합니다 — 스팸 발신자가 수법을 바꾸는 순간 규칙이 뚫리고, 규칙을 계속 추가해야 하는 악순환이 생깁니다. 머신러닝은 이 순서를 뒤집습니다. "스팸/정상"이라고 표시된 이메일 수천 통을 주면, 어떤 단어 조합이 스팸을 가르는지는 모델이 데이터에서 스스로 찾아냅니다. 전통 프로그래밍이 `규칙 + 데이터 → 결과`라면, 머신러닝은 `데이터 + 결과 → 규칙(가중치)`인 셈입니다.

## 세 가지 학습 방식

- **지도학습** — 입력과 정답이 짝지어진 데이터로 학습합니다. "사진 1만 장에 고양이/개 라벨이 붙어 있다, 구분하는 법을 배워라" 같은 문제입니다. 실무에서 압도적으로 많이 쓰이는 방식이고, 이 볼트가 다루는 [[선형 회귀]]·[[로지스틱 회귀]]·[[결정 트리]] 등이 전부 여기 속합니다.
- **비지도학습** — 정답 라벨 없이 입력만 주고 구조를 찾게 합니다. "고객 구매 이력 1만 건에서 자연스러운 그룹을 찾아라" 같은 문제로, [[비지도 학습]] 노트에서 클러스터링을 다룹니다.
- **강화학습** — 에이전트가 행동하고 보상/페널티를 받으며 전략을 배웁니다. 게임 AI나 로봇 제어가 대표적이고, LLM 쪽에서는 [[RLHF]] 계열이 여기서 갈라져 나온 개념입니다.

분류(Classification)와 회귀(Regression)는 지도학습을 출력 형태로 나눈 것입니다 — "이 이메일이 스팸인가?"처럼 이산적인 범주를 답하면 분류, "이 집 가격은 얼마인가?"처럼 연속적인 숫자를 답하면 회귀입니다.

## 왜 이게 중요한가 — 훈련/검증/테스트 분할

모델이 "외운 것"과 "배운 것"을 구분하려면, 학습에 쓰지 않은 데이터로 평가해야 합니다. 그래서 데이터를 보통 훈련 60~80% / 검증 10~20% / 테스트 10~20%로 나눕니다. 훈련 집합으로 파라미터를 조정하고, 검증 집합으로 하이퍼파라미터를 고르고, 테스트 집합은 맨 마지막에 딱 한 번만 열어봅니다. 테스트 성능을 보고 나서 모델을 다시 손보면, 그 순간부터 테스트 집합은 사실상 훈련에 쓰인 것이나 마찬가지라 숫자를 믿을 수 없게 됩니다. 이 원칙은 나중에 [[모델 평가]]와 [[편향-분산 트레이드오프]] 전체를 관통합니다.
