# KNN

새로운 데이터 점이 들어오면, 훈련 데이터 중 가장 가까운 K개를 찾아 그들의 다수결(분류)이나 평균(회귀)으로 답을 정하는 알고리즘입니다. 학습 단계에서 미리 계산해두는 게 없고 예측 시점에 매번 거리를 전부 계산하는 "게으른 학습"이라는 게 특징이며, K는 [[편향-분산 트레이드오프]]를 직접 조절합니다(K=1은 이웃 하나에만 휘둘려 과적합, K가 전체 데이터 수에 가까우면 다 뭉뚱그려 과소적합). 거리는 보통 유클리드 거리를 쓰지만 이상치에 강한 L1이나 텍스트·임베딩에 적합한 코사인 거리로 바꿀 수 있고, 특성이 수십~수백 차원을 넘어가면 모든 점들 사이의 거리가 서로 비슷해져버려 "가장 가까운 이웃"이라는 개념 자체가 무의미해지는 차원의 저주가 나타나므로 실무에서는 대략 20~50개 특성까지가 KNN이 잘 작동하는 범위입니다.
