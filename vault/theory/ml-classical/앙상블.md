# 앙상블

약한 모델 여러 개를 적절히 합치면 하나의 강한 모델보다 나은 성능을 낸다는 아이디어입니다. 배깅은 데이터를 중복 허용 샘플링(부트스트랩)해 만든 여러 데이터셋으로 모델을 독립적으로 학습시킨 뒤 예측을 평균 내는 방식으로, 개별 모델의 분산은 높아도 평균을 내면 분산이 크게 줄어듭니다 — 랜덤 포레스트가 대표적이고 [[편향-분산 트레이드오프]]에서 "분산을 줄이는" 축입니다. 부스팅은 반대로 이전 모델이 틀린 부분에 집중해 순차적으로 모델을 추가해가는 방식(AdaBoost, XGBoost 등)이라 편향을 줄이는 데 효과적이지만 너무 오래 돌리면 과적합 위험이 있습니다. 두 방식 모두 핵심 전제는 "다양성"입니다 — 모델들이 서로 다른 실수를 해야 합쳐졌을 때 실수가 상쇄됩니다.
