# 나이브 베이즈

베이즈 정리를 "모든 특성은 클래스가 주어지면 서로 독립"이라는 (실제로는 대체로 틀린) 가정으로 단순화한 확률 분류기입니다. `P(클래스|특성) = P(특성|클래스)·P(클래스) / P(특성)`을 계산해 가장 확률이 높은 클래스를 고르는데, 예컨대 "무료"와 "당첨"이라는 단어가 실제로는 서로 독립이 아님에도 스팸 필터가 여전히 잘 동작하는 이유는 최종적으로 필요한 게 정확한 확률값이 아니라 클래스 간의 순위이기 때문입니다 — 독립 가정이 만드는 오차가 모든 클래스에 비슷하게 걸리면 상대적 순위는 그대로 유지됩니다. 훈련 데이터에 없던 단어의 확률이 0이 되어 전체 곱셈을 0으로 만들어버리는 것을 막기 위해 라플라스 평활(각 카운트에 작은 값 α를 더함)을 적용하는 것이 실무 구현의 핵심입니다.
