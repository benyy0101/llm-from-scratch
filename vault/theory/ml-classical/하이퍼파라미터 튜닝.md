# 하이퍼파라미터 튜닝

학습률이나 트리 깊이처럼 학습 과정에서 자동으로 조정되지 않고 훈련 전에 사람이 미리 정해야 하는 값(하이퍼파라미터)을 최적화하는 작업입니다. 그리드서치는 지정한 값들의 모든 조합을 다 평가하는 방식이라 확실하지만, 하이퍼파라미터가 6개고 각각 5개 값을 시도하면 15,625번을 평가해야 해서 차원이 늘수록 비용이 폭발적으로 커집니다. 랜덤서치는 같은 평가 횟수(예: 50회)로도 각 파라미터에서 훨씬 다양한 값을 시도할 수 있어(그리드서치가 파라미터당 3개 값만 보는 동안 랜덤서치는 50개 값을 봄) 대부분의 문제에서 더 효율적이고, 베이지안 최적화는 지금까지의 평가 결과를 학습해 다음에 어디를 시도할지 지능적으로 고르는 방식이라 보통 2~5배 적은 시도로 비슷하거나 더 나은 결과를 찾습니다. 실무에서는 가장 영향이 큰 학습률부터 로그 스케일(0.1, 0.01, 0.001…)로 탐색하는 것이 정석입니다.
