# 피처 선택

수백 개의 특성 중 실제로 신호를 담은 소수만 골라내는 작업으로, "특성이 많을수록 좋다"가 아니라 "올바른 특성일수록 좋다"는 게 핵심입니다. 필터 방식은 분산이나 상호정보량 같은 통계량만으로 각 특성에 독립적으로 점수를 매겨 빠르지만 특성 간 상호작용은 못 잡고, 래퍼 방식(RFE 등)은 실제 모델 성능으로 특성 부분집합을 평가해 정확하지만 모델을 반복해서 재훈련해야 해 계산 비용이 큽니다. 임베디드 방식(L1 정규화, 트리 기반 중요도)은 모델을 훈련하는 과정 자체에서 자동으로 불필요한 특성의 가중치를 0으로 밀어내 한 번의 훈련으로 선택까지 끝낸다는 장점이 있습니다.
