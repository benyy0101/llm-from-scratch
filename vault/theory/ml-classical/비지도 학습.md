# 비지도 학습

정답 라벨 없이 입력 데이터만 놓고 그 안의 구조를 스스로 찾아내는 학습 방식입니다. 가장 흔한 형태는 클러스터링으로, 비슷한 데이터끼리 묶는 것입니다. K-Means는 클러스터 개수 K를 미리 정하고 중심점을 반복 갱신해가며 데이터를 K개 그룹으로 나누는 방식이라 구형에 가까운 클러스터에 잘 맞고, DBSCAN은 밀도가 높은 영역을 자동으로 찾아 클러스터 개수를 미리 정하지 않고도 불규칙한 모양의 클러스터와 노이즈 점을 함께 구분해냅니다. 클러스터링 결과가 얼마나 잘 나눠졌는지는 같은 클러스터 안의 거리와 다른 클러스터까지의 거리를 비교하는 실루엣 스코어 같은 지표로 검증합니다.
