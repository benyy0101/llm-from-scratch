# 시계열

"오늘 주가는 어제 주가에 의존한다"처럼 데이터가 서로 독립이 아니라 시간 순서에 종속된 데이터입니다. 표준 ML은 데이터가 서로 독립(i.i.d.)이라고 가정하기 때문에, 시계열 데이터를 무작위로 섞어 훈련/테스트로 나누면 미래 정보가 훈련 데이터에 새어 들어가 평가 결과를 신뢰할 수 없게 됩니다 — 그래서 항상 훈련 구간이 테스트 구간보다 시간상 앞서도록 나누는 워크포워드 검증을 씁니다. 과거 값을 입력 특성으로 바꾸는 지연 특성(lag feature)을 만들면 시계열 문제를 일반적인 지도학습 문제로 바꿀 수 있고, 평균·분산·자기상관이 시간에 따라 변하지 않는 정상성은 대부분의 예측 모델이 전제하는 조건이라 비정상 시계열은 차분(현재값-이전값)을 거쳐 정상화합니다.
