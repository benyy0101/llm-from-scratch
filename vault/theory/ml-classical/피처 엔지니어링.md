# 피처 엔지니어링

원본 데이터를 모델이 패턴을 더 쉽게 찾을 수 있는 형태로 가공하는 작업으로, 고전 ML에서는 종종 어떤 알고리즘을 쓰느냐보다 어떤 특성을 넣어주느냐가 성능을 더 크게 좌우합니다. 수치형 데이터는 평균 0·표준편차 1로 맞추는 표준화나 로그 변환(한쪽으로 치우친 분포를 완화)을 거치고, 범주형 데이터는 원-핫 인코딩(각 범주를 별도 0/1 열로)이나 라벨 인코딩(정수로 매핑, 트리 기반 모델에만 적합)으로 바꾸며, 텍스트는 단순 단어 빈도보다 희귀하고 특징적인 단어에 더 큰 가중치를 주는 TF-IDF가 흔히 쓰입니다. 거리 기반 알고리즘([[KNN]] 등)은 특성 스케일이 다르면 큰 값의 특성이 거리를 지배해버리므로 스케일링이 사실상 필수입니다.
