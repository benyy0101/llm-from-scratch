# 선형 회귀

입력 x와 출력 y 사이에 `y = wx + b` 형태의 직선 관계를 가정하고, 이 직선이 실제 데이터를 가장 잘 지나가도록 w(기울기)와 b(절편)를 찾는 방법입니다. 특성이 여러 개면 `y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b`로 확장되는데, 이때도 여전히 "가중치들의 선형 결합"이라는 점은 같습니다.

"가장 잘 지나간다"를 숫자로 정의한 것이 평균제곱오차(MSE)입니다.

```
MSE = (1/n) Σ (예측값 - 실제값)²
```

오차를 제곱하는 이유는 두 가지입니다. 오차 10은 오차 1보다 100배 더 나쁘다고 취급해서 큰 실수에 훨씬 강한 페널티를 주고, 동시에 이 함수가 모든 지점에서 매끄럽게 미분 가능해 최적화하기 쉬운 그릇 모양(볼록함수)을 만들어주기 때문입니다.

## 경사하강법 — 그릇 바닥을 찾아 내려가기

w와 b를 무작위(보통 0)로 시작해서, MSE가 줄어드는 방향으로 조금씩 이동시킵니다.

```
w ← w - lr × ∂MSE/∂w
b ← b - lr × ∂MSE/∂b
```

`lr`(학습률)은 한 번에 얼마나 이동할지를 정합니다. 너무 크면 그릇 바닥을 지나쳐 발산하고, 너무 작으면 수렴에 한없이 오래 걸립니다 — 실무에서는 0.01, 0.001 같은 값에서 시작해 조정합니다. 특성마다 값의 범위가 크게 다르면(하나는 0~1, 하나는 0~100만) 그릇이 한쪽으로 심하게 찌그러져 경사하강법이 잘 안 굴러가므로, 학습 전에 평균 0·표준편차 1로 맞추는 표준화가 사실상 필수입니다.

데이터가 작으면 반복 없이 한 번에 최적해를 계산하는 정규방정식(`w = (XᵀX)⁻¹Xᵀy`)도 쓸 수 있지만, 특성 수의 세제곱에 비례해 계산량이 늘어나 데이터가 크면 경사하강법이 유리합니다.

## 다항식 회귀와 정규화 — 과적합의 첫 번째 예시

`y = w₁x + w₂x² + w₃x³ + b`처럼 x의 거듭제곱을 특성으로 추가하면 곡선도 표현할 수 있습니다(가중치에 대해서는 여전히 선형이라 "선형" 회귀라는 이름을 유지합니다). 문제는 차수를 너무 올리면 생깁니다 — 데이터 10개에 10차 다항식을 맞추면 그 10개 점은 완벽하게 통과하지만, 점과 점 사이에서 곡선이 요동치며 새 데이터에는 형편없는 예측을 내놓습니다. 이게 [[편향-분산 트레이드오프]]에서 말하는 "과적합"의 가장 눈에 보이는 예시입니다.

해결책 중 하나가 릿지 회귀(L2 정규화)입니다. 비용함수에 가중치 크기에 대한 페널티를 더합니다.

```
Cost = MSE + λ Σ wᵢ²
```

λ를 키우면 가중치들이 0 쪽으로 눌려서 모델이 단순해지고(분산 감소, 편향 증가), λ를 줄이면 원래 MSE만 최소화하는 모델에 가까워집니다.

## 왜 이게 중요한가

MSE·경사하강법·정규화라는 세 가지 개념은 선형 회귀에서 처음 등장하지만, 신경망 학습([[역전파]]류 노트)에서도 손실을 정의하고 줄이는 데 그대로 재사용되는 기본 골격입니다. 모델이 아무리 복잡해져도 "손실 함수를 정의하고 → 그래디언트를 구하고 → 파라미터를 그 반대 방향으로 조금씩 옮긴다"는 틀 자체는 바뀌지 않습니다.
