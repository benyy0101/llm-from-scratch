# 복소수와 푸리에 변환

복소수는 "허수"라는 이름과 달리 사실 **회전을 표현하는 도구**입니다. 오일러 공식 `e^(iθ) = cos(θ) + i·sin(θ)`가 지수함수와 삼각함수(회전)를 하나로 묶어주고, 허수 단위 i를 곱하는 건 기하학적으로 90도 회전과 같습니다.

**LLM과의 직접적인 연결고리는 위치 인코딩입니다.** 원조 Transformer가 위치마다 서로 다른 주파수의 sin/cos 쌍을 쓰는 건 사실 복소 지수 함수의 실수부·허수부를 따로 뽑아 쓰는 것과 같고, 최신 모델들이 쓰는 [[위치 인코딩|RoPE(회전 위치 임베딩)]]은 한 걸음 더 나아가 Query·Key 벡터에 복소수 회전을 직접 곱해서 "토큰 간 상대적 위치 차이"를 회전각 하나로 인코딩합니다 — 복소수 곱셈이 순수한 회전이라는 성질을 그대로 활용한 것입니다.

## 푸리에 변환 — 모든 신호는 사인파의 합이다

이산 푸리에 변환(DFT)은 시간 영역의 신호를 주파수 영역으로 분해합니다. 직접 계산하면 O(N²)이지만 FFT(고속 푸리에 변환) 알고리즘으로 O(N log N)까지 줄어들어서 대규모 신호 처리가 실용적이게 됩니다.

두 가지 실무 연결점이 있습니다:
- **합성곱 정리** — 시간 영역의 합성곱은 주파수 영역의 단순한 곱셈과 같습니다. CNN의 슬라이딩 필터 연산이 수학적으로 FFT→곱셈→역변환과 동등하다는 뜻이고, 커널이 클 때는 FFT 기반 계산이 더 효율적입니다.
- **음성 모델** — Whisper 같은 음성 인식 모델은 원본 파형 대신 멜-스펙트로그램(겹치는 시간 구간마다 FFT를 돌려 만든 시간×주파수 2D 표현)을 입력으로 씁니다.

## 왜 얕게만 다루는가

이 두 주제는 LLM 텍스트 서빙 자체와는 거리가 있고, 이미지/음성 모델링이나 신호 처리 쪽에서 본령을 발휘합니다. 다만 위치 인코딩의 수학적 뿌리가 여기 있다는 것만은 짚어둘 가치가 있습니다.
