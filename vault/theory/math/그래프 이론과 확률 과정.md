# 그래프 이론과 확률 과정

## 그래프 이론 — 관계 자체가 정보인 데이터

노드(정점)와 엣지(간선)로 표현되는 데이터입니다. 인접행렬 `A[i][j]=1`(노드 i와 j가 연결됨)로 구조를 수치화하고, 라플라시안 행렬 `L = D - A`(D는 차수 행렬)의 고유값 개수가 그래프의 연결 요소 개수를 알려줍니다.

그래프 신경망(GNN)의 핵심 연산인 "메시지 패싱"(각 노드가 이웃 노드들의 정보를 모아 자기 상태를 업데이트)은 사실 **인접행렬과 특성 행렬의 [[벡터와 행렬|행렬곱]]**입니다. 소셜 네트워크(친구의 구매 이력이 개인 이력보다 강한 신호일 때), 분자 구조(원자보다 결합 관계가 핵심일 때), 추천 시스템의 사용자-아이템 그래프 등, 데이터를 독립된 행으로 취급하는 일반 ML과 달리 **연결 구조 자체가 정보인 문제**에 쓰입니다.

## 확률 과정 — 시간에 따라 진화하는 무작위성

**무작위 보행**: 동전 던지기로 좌우로 움직이는 과정. n걸음 후 원점에서 예상 거리가 `√n`에 비례한다는 게 핵심 스케일링입니다 — 방향이 편향되지 않아도 점점 멀어진다는 뜻입니다.

**마르코프 연쇄**: "현재 상태만 다음 상태를 결정한다"(과거 이력 무관)는 원리. 전이 행렬 `P[i][j]`(상태 i에서 j로 갈 확률)로 표현하고, 반복하면 정상 분포(stationary distribution)로 수렴합니다. **언어모델이 다음 토큰을 현재까지의 문맥(hidden state)만으로 결정하는 것도 사실상 마르코프 연쇄를 고차원으로 확장한 것**이고, [[샘플링 방법|temperature로 분포를 조절]]하는 것도 이 전이 확률을 매번 다시 매만지는 것입니다. MCMC(Metropolis-Hastings)가 정규화 상수를 몰라도 목표 분포를 탐색할 수 있는 이유도 마르코프 연쇄의 정상 분포 수렴 성질 덕분입니다.

**확산 모델과의 연결**: 정방향 과정(데이터에 노이즈를 점점 더해 순수 잡음으로 만듦)은 브라운 운동이고, 역방향 과정(신경망이 노이즈를 한 단계씩 제거해 데이터를 복원)은 이 마르코프 연쇄를 학습으로 뒤집는 것입니다. 각 노이즈 제거 스텝은 [[샘플링 방법|재매개변수화 트릭]]으로 미분 가능하게 구현됩니다.

## 왜 얕게만 다루는가

두 주제 모두 LLM 텍스트 서빙의 핵심 경로(어텐션·KV 캐시·양자화)와는 거리가 있어서 여기서는 "언어모델의 토큰 생성이 마르코프 연쇄다"라는 정도의 연결고리만 짚습니다. 그래프 신경망이나 확산 모델을 깊게 다루려면 각각 별도의 이론 레이어가 필요합니다.
