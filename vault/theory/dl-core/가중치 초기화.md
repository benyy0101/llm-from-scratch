# 가중치 초기화

학습을 시작하기 전, 가중치에 처음 넣는 값을 어떻게 고르느냐가 그 네트워크가 애초에 학습 가능한지를 결정합니다. 직관과 달리 "그냥 무작위로 넣으면 되지 않나"는 답이 아닙니다 — 무작위의 **크기(분산)**를 잘못 고르면 층을 몇 개만 통과해도 신호가 사라지거나 무한대로 터집니다.

## 왜 전부 0으로 두면 안 되는가 — 대칭성 문제

모든 가중치를 0(또는 서로 같은 값)으로 초기화하면, 한 층 안의 모든 뉴런이 완전히 같은 입력을 받아 같은 출력을 내고, [[역전파]]에서도 같은 기울기를 받아 매 스텝 똑같이 업데이트됩니다. 뉴런이 512개 있어도 실질적으로는 뉴런 1개가 512번 복제된 것과 다를 게 없습니다 — 파라미터 512개분의 비용을 냈지만 표현력은 1개짜리입니다. 그래서 초기화는 반드시 뉴런마다 다른 값에서 출발해야 하고(**대칭성 깨기, symmetry breaking**), 이것이 무작위 초기화가 필요한 첫 번째 이유입니다.

## 분산이 신호를 얼마나 증폭시키는가

입력 `fan_in`개를 받는 뉴런의 가중합 `z = Σwᵢxᵢ`의 분산은 근사적으로 `Var(z) = fan_in × Var(w) × Var(x)`입니다. `fan_in=512`에 `Var(w)=1`이면 한 층만 지나도 분산이 512배로 불어나고, 10개 층을 통과하면 `512¹⁰ ≈ 10²⁷`으로 발산합니다. 반대로 `Var(w)=0.001`이면 층마다 분산이 절반 이하로 줄어 10개 층 뒤엔 `10⁻⁴` 수준으로 사실상 소멸합니다. 초기화의 목표는 각 층을 지나도 `Var(z) ≈ Var(x)`를 유지하도록 `Var(w)`를 역산하는 것입니다.

## Xavier/Glorot 초기화 — 시그모이드·Tanh용

```
Var(w) = 2 / (fan_in + fan_out)
```

시그모이드와 tanh는 0 근처에서 거의 선형이므로, 순전파(fan_in 방향)와 역전파(fan_out 방향) 양쪽의 분산을 동시에 고려해 두 값을 더한 분모로 나눕니다(Glorot & Bengio, 2010). 예를 들어 784→128 층이면 `std=√(2/(784+128))≈0.047`입니다. 이 값으로 초기화하면 시그모이드/tanh 네트워크를 수십 층까지도 안정적으로 학습시킬 수 있습니다.

## Kaiming/He 초기화 — ReLU 계열용

ReLU는 입력의 절반가량(평균적으로)을 0으로 깎아버리므로, Xavier 공식을 그대로 쓰면 층을 지날 때마다 분산이 대략 절반씩 줄어 50층이면 `0.5⁵⁰≈10⁻¹⁶`로 신호가 완전히 죽습니다. He et al.(2015)은 이 손실을 보정해 fan_out 없이 fan_in만 쓰고 계수를 2배로 늘렸습니다.

```
Var(w) = 2 / fan_in
```

`fan_in=512`면 `std=√(2/512)≈0.0625`로, 같은 조건의 Xavier(`≈0.033`)보다 약 1.9배 큽니다 — ReLU의 "50% 죽임"을 미리 보상해 넣은 크기입니다. GELU·Swish·Leaky ReLU도 완전히 0으로 깎지는 않지만 대체로 Kaiming 초기화를 그대로 씁니다.

## 초기화 전략 선택

```
활성화 함수가 시그모이드/Tanh   → Xavier/Glorot
활성화 함수가 ReLU/Leaky ReLU/GELU/Swish → Kaiming/He
트랜스포머 잔차 연결                → 아래 잔차 스케일링 추가 적용
```

## 트랜스포머의 잔차 스케일링

트랜스포머는 `x = x + sublayer(x)` 형태의 잔차 연결(residual connection)을 층마다 반복합니다. 이러면 각 층을 지날 때마다 분산이 계속 더해져서, 126층짜리 모델(예: LLaMA 3 405B)이면 초기 분산이 이론상 126배까지 누적될 수 있습니다. GPT-2가 도입한 해법은 잔차 경로의 가중치에 `1/√(2N)`(N=전체 잔차 층 수)을 곱해, 층 하나가 전체 분산에 기여하는 몫을 `1/(2N)` 수준으로 미리 눌러두는 것입니다 — 층 수가 많을수록 층 하나의 초기 기여를 그만큼 더 작게 시작합니다.

## 정량적으로 본 결과 (50층 네트워크)

| 초기화 | 1층 | 10층 | 50층 |
|---|---|---|---|
| 영(0) 초기화 | 대칭 | 대칭 | 대칭 (학습 불가) |
| N(0,1), ReLU | 정상 | 폭발 | 발산 |
| N(0,0.01), ReLU | 정상 | 거의 0 | 소실 |
| Xavier + Sigmoid | 정상 | 정상 | 정상 |
| Kaiming + ReLU | 정상 | 정상 | 정상 |

배치/레이어 정규화([[정규화 (드롭아웃·가중치 감쇠)]])를 함께 쓰면 초기화가 다소 거칠어도 학습이 버텨내지만, 정규화가 없거나 네트워크가 아주 깊다면 초기화 선택이 학습 성패를 가르는 결정적 변수가 됩니다.
