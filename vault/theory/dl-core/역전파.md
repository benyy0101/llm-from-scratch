# 역전파

파라미터가 230만 개인 네트워크에서 "가중치 하나를 살짝 바꿔보고 손실이 얼마나 변하는지 재보는" 방식으로 모든 가중치의 기울기를 구하려면 [[다층 신경망과 순전파|순전파]]를 230만 번 다시 돌려야 합니다. 역전파는 이 문제를 **순전파 한 번 + 역전파 한 번**으로 끝냅니다 — 정확히는 손실에서 출발해 [[다층 신경망과 순전파|순전파]]가 지나온 길을 거꾸로 되짚으며, 각 연산의 "국소 미분"만 곱해나가는 방식입니다. 이 알고리즘이 없었다면 지금의 딥러닝은 계산량 때문에 애초에 불가능했을 것입니다.

## 연쇄법칙을 신경망에 그대로 적용하기

역전파의 수학적 근거는 [[연쇄법칙과 자동미분]]에서 다루는 연쇄법칙 `dy/dx = f'(g(x))·g'(x)` 그 자체입니다. 2층 네트워크 `z₁=W₁x+b₁, a₁=σ(z₁), z₂=W₂a₁+b₂, a₂=σ(z₂), L=(a₂-y)²`를 예로 들면, 손실에서 첫 층의 가중치까지 미분이 사슬처럼 이어집니다.

```
dL/da₂ = 2(a₂-y)
dL/dz₂ = dL/da₂ · σ'(z₂)          ← σ'(z)=σ(z)(1-σ(z))
dL/dW₂ = dL/dz₂ · a₁,   dL/db₂ = dL/dz₂
dL/da₁ = dL/dz₂ · W₂               ← 여기서 다음 층으로 "역전파"
dL/dz₁ = dL/da₁ · σ'(z₁)
dL/dW₁ = dL/dz₁ · x,    dL/db₁ = dL/dz₁
```

핵심은 각 파라미터의 기울기가 "손실에서 그 파라미터까지 거슬러 올라가며 만난 국소 미분들의 곱"이라는 점입니다. 층이 아무리 많아도 이 곱셈 사슬을 한 번만 왼쪽으로 훑으면 모든 기울기가 동시에 나옵니다.

## Computational Graph — 연산을 그래프로 보기

역전파를 실제로 구현할 때는 수식을 통째로 손으로 미분하는 대신, 모든 연산(덧셈·곱셈·시그모이드 등)을 노드로 하고 값의 흐름을 엣지로 하는 그래프를 만듭니다. 그래프의 각 노드는 자기 자신의 국소 미분만 알면 되고, 전체 기울기는 이 노드들을 연쇄법칙으로 이어 붙여서 자동으로 계산됩니다.

```mermaid
flowchart LR
    subgraph 순전파 순서 →
    X["x"] --> M["z = w·x"]
    M --> A["z + b"]
    A --> S["a = sigmoid(z)"]
    S --> L["L = (a-y)²"]
    end
```
```mermaid
flowchart RL
    subgraph 역전파 순서 ←
    L2["dL/dL = 1"] --> S2["dL/da → dL/dz\n(× a(1-a))"]
    S2 --> A2["dL/dz → dL/db\n(그대로 전달)"]
    A2 --> M2["dL/dz → dL/dw\n(× x)"]
    end
```

**덧셈과 곱셈의 기울기 전달 방식이 다릅니다.** `c = a+b`는 들어온 기울기를 양쪽에 그대로(×1) 나눠주지만, `c = a×b`는 `∂c/∂a = b`, `∂c/∂b = a`라서 **서로 상대방의 값만큼** 기울기를 나눠 받습니다 — 곱셈에서는 큰 쪽 입력이 작은 쪽보다 상대적으로 더 큰 수정 신호를 받는다는 뜻입니다.

한 값이 그래프 안에서 두 갈래 이상의 경로로 쓰였다면(예: `b=a*a`처럼 자기 자신을 두 번 사용), 그 값의 최종 기울기는 **모든 경로에서 온 기울기의 합**이어야 합니다. 그래서 구현에서는 기울기를 `=`가 아니라 `+=`로 누적하고, 모든 자식 노드의 기울기가 다 모인 뒤에야 부모 노드를 처리하도록 순서(위상 정렬)를 지킵니다 — 순서를 어기면 아직 안 끝난 경로의 기울기가 누락됩니다.

## 사라지는 기울기(Vanishing Gradient)

시그모이드의 미분 `σ'(z)=σ(z)(1-σ(z))`은 최댓값이 `z=0`일 때 딱 **0.25**입니다. L층 네트워크를 통과하며 이 값이 층마다 곱해지므로, 최악의 경우 첫 층이 받는 기울기는 마지막 층 기울기의 `0.25^(L-1)`로 줄어듭니다.

| 층 수 | 감쇠 계수 | 남는 신호 |
|---|---|---|
| 3층 | 0.25³ | 1.56% |
| 5층 | 0.25⁵ | 0.1% |
| 10층 | 0.25¹⁰ | 0.0001% |

10층짜리 시그모이드 네트워크의 첫 층은 사실상 아무 신호도 못 받는다는 뜻입니다. 이건 역전파 알고리즘 자체의 결함이 아니라 시그모이드가 출력을 (0,1)로 "짓누르기" 때문에 생기는 현상입니다 — 그래서 실무에서는 시그모이드 대신 미분값이 1인 구간을 가진 [[활성화 함수|ReLU 계열]]을 은닉층에 쓰고, [[가중치 초기화]]와 정규화로 신호 크기를 관리합니다.

## 순전파와 역전파의 메모리-계산 트레이드오프

순전파 중 계산되는 중간값(z₁, a₁, z₂, a₂ …)은 버리지 않고 메모리에 저장해뒀다가 역전파에서 그대로 재사용합니다. 이렇게 하면 계산량이 정확히 2배(순전파 1회+역전파 1회)로 끝나지만, 메모리는 그만큼 더 씁니다. 이 트레이드오프를 반대로 뒤집어 "메모리를 아끼는 대신 일부 중간값을 역전파 때 다시 계산"하는 기법이 있는데(Gradient Checkpointing), 큰 모델을 학습할 때 GPU 메모리가 부족하면 실제로 쓰입니다.

추론(서빙)에서는 이 저장이 아예 필요 없습니다. 가중치가 고정된 채 순전파만 흘려보내면 되므로 메모리도 적게 쓰고 속도도 빠릅니다 — 지금 이 vault가 다루는 "서빙"은 전부 역전파가 꺼진 순전파 전용 상태라고 볼 수 있습니다.
