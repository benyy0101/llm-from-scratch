# 활성화 함수

[[다층 신경망과 순전파]]에서 각 층은 `z = W·x + b` 다음에 반드시 비선형 함수를 하나 통과시킵니다. 이 함수가 활성화 함수입니다. 없어도 되지 않을까 싶지만, 없으면 신경망은 아무리 층을 쌓아도 사실상 층 하나짜리와 똑같아집니다.

## 왜 없으면 안 되는가 — 선형의 함정

활성화 함수 없이 층을 두 개 이으면:

```
y = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁+b₂) = Ax + c
```

100개 층을 쌓아도 결국 하나의 행렬 `A`와 편향 `c`로 축약됩니다 — 선형 변환을 아무리 합성해도 결과는 선형 변환이기 때문입니다. 이러면 [[퍼셉트론]] 노트에서 본 XOR도, 나선형 데이터도, 이미지 속 얼굴도 구분할 수 없습니다. 활성화 함수는 이 선형 사슬을 층마다 끊어내는 "매듭"입니다 — 활성화 함수가 없으면 깊이는 그저 착시일 뿐입니다.

## 주요 함수와 각각의 사정

**시그모이드** `σ(z)=1/(1+e^-z)`, 출력 (0,1). 미분 최댓값이 0.25뿐이라 층이 깊어지면 [[역전파]]에서 본 것처럼 기울기가 급격히 사라집니다. 게다가 출력이 항상 양수라서 가중치 기울기 부호가 한쪽으로 쏠려 학습 경로가 지그재그로 흔들립니다.

**Tanh** `(e^z-e^-z)/(e^z+e^-z)`, 출력 (-1,1). 영점 중심이라 지그재그 문제는 줄지만 미분 최댓값이 1.0이어도 입력이 커지면 여전히 0에 가까워져(포화, saturation) 깊은 네트워크에서는 기울기 소실이 남습니다.

**ReLU** `max(0, z)`. 양수 구간에서 미분이 정확히 1이라 기울기가 깎이지 않고 그대로 전달됩니다 — 깊은 네트워크를 실제로 학습 가능하게 만든 전환점입니다. 하지만 어떤 뉴런이 우연히 항상 음수 입력만 받게 되면 출력도 미분도 영원히 0이 되어 그 뉴런은 죽습니다("dead neuron"). 실전 네트워크에서 뉴런의 10~40%가 죽는 경우도 관찰됩니다.

**Leaky ReReLU** `x (x>0), 0.01x (x≤0)`. 음수 구간에도 작은 기울기를 남겨 죽은 뉴런이 다시 살아날 여지를 줍니다.

**GELU** `x·Φ(x)` (Φ는 표준정규분포 누적분포함수). 입력을 "이 값이 양수일 확률"만큼 통과시키는 부드러운 게이트로 볼 수 있습니다. ReLU처럼 딱 잘라 0으로 만들지 않고 매끄럽게 깎기 때문에 dead neuron 문제가 사실상 사라지고, BERT·GPT 등 현대 트랜스포머 은닉층의 기본값입니다.

**Swish/SiLU** `x·sigmoid(x)`. GELU와 발상이 비슷하고(자기 자신의 시그모이드로 게이팅) 성능도 비슷합니다. 비전 모델(EfficientNet)에서 특히 선호됩니다.

**Softmax** `e^xᵢ / Σⱼe^xⱼ`. 벡터를 "합이 1인 확률분포"로 바꿔주는 출력층 전용 함수 — 다중 클래스 분류의 표준이자, [[Query·Key·Value]]에서 어텐션 점수를 가중치로 바꾸는 데도 그대로 쓰입니다.

## 10층 네트워크에서의 신호 감쇠 비교

| 활성화 함수 | 층당 평균 미분 | 10층 누적 |
|---|---|---|
| Sigmoid | 0.25 | 약 0.00001% 남음 |
| Tanh | ~0.7 | 약 2.8% 남음 |
| ReLU | 1.0 | **100% 유지** |
| GELU | ~0.8 | 약 10.7% 남음 |

## 선택 기준

은닉층은 트랜스포머/NLP라면 GELU, CNN/비전이면 ReLU나 Swish, RNN 게이트 안쪽은 여전히 시그모이드/tanh를 씁니다. 출력층은 이진 분류면 시그모이드, 다중 분류면 softmax, 회귀면 활성화 없이 그대로(선형) 출력합니다 — 이 선택은 [[손실 함수]]와 짝을 이룹니다(예: softmax + cross-entropy는 역전파 시 놀라울 만큼 단순한 기울기로 정리됩니다).
