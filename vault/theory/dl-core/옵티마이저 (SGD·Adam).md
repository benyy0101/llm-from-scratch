# 옵티마이저 (SGD·Adam)

[[역전파]]가 기울기(gradient)를 계산해주면, 그 기울기를 가지고 실제로 가중치를 얼마나 어느 방향으로 움직일지 결정하는 것이 옵티마이저입니다. 가장 단순한 규칙은 "기울기의 반대 방향으로 한 걸음"인데, 실제로는 이 한 걸음의 크기와 방향을 똑똑하게 조절하는 여러 세대의 개선이 있었습니다.

## SGD — 출발점이자 세 가지 문제의 근원

```
w ← w - lr × gradient
```

전체 데이터 대신 미니배치의 기울기만으로 매번 업데이트합니다. 이 단순함 때문에 세 가지 문제가 생깁니다.

1. **진동** — 손실 지형이 좁고 긴 계곡 모양이면, 기울기는 계곡을 가로지르는 가파른 방향을 가리켜서 정작 필요한 방향(계곡을 따라가는 완만한 방향)으로는 거의 못 나아가고 좌우로 왔다 갔다 합니다.
2. **모든 파라미터에 같은 학습률** — 어떤 가중치는 아직 한참 못 미쳐서 크게 움직여야 하고, 어떤 가중치는 최적값 근처라 미세 조정만 필요한데, 학습률 하나로는 이 둘을 동시에 만족시킬 수 없습니다.
3. **안장점(saddle point)** — 고차원에서는 기울기가 거의 0인 평평한 지점이 흔한데, SGD는 여기서 사실상 멈춰버립니다.

## Momentum — 진동을 상쇄하고 방향을 가속

```
m ← β·m + gradient
w ← w - lr·m
```

과거 기울기를 지수적으로 누적한 속도 `m`을 유지합니다. β=0.9면 대략 최근 10개 기울기의 평균(`1/(1-0.9)=10`)과 같습니다. 계곡을 가로지르는 성분은 스텝마다 부호가 뒤집혀 누적하면 서로 상쇄되고, 계곡을 따라가는 성분은 매번 같은 방향이라 누적될수록 커집니다 — 결과적으로 진동은 줄고 유용한 방향으로는 가속됩니다. 실측으로도 SGD 단독 대비 2~3배 빠른 수렴을 보입니다.

## RMSProp — 파라미터마다 다른 학습률

```
s ← β·s + (1-β)·gradient²
w ← w - lr·gradient / (√s + ε)
```

파라미터별로 "최근 기울기 제곱의 이동평균" `s`를 따로 추적합니다. 꾸준히 큰 기울기를 받아온 파라미터는 `s`가 커서 나눗셈 결과(실효 학습률)가 작아지고, 꾸준히 작은 기울기만 받던 파라미터는 상대적으로 더 크게 업데이트됩니다 — SGD의 두 번째 문제(모든 파라미터가 같은 학습률)를 해결한 첫 실용적 방법입니다. `ε`(보통 1e-8)은 `s`가 0에 가까울 때 0으로 나누는 사고를 막는 안전장치입니다.

## Adam — Momentum과 RMSProp의 결합 + 초기 편향 보정

```
m ← β₁·m + (1-β₁)·gradient        (1차 모멘트: momentum과 동일)
v ← β₂·v + (1-β₂)·gradient²       (2차 모멘트: RMSProp과 동일)
m̂ = m / (1-β₁ᵗ)                   (편향 보정)
v̂ = v / (1-β₂ᵗ)
w ← w - lr · m̂ / (√v̂ + ε)
```

기본값은 `lr=0.001, β₁=0.9, β₂=0.999, ε=1e-8`이며, 어떤 아키텍처든 일단 이 값으로 시작해도 크게 틀리지 않습니다.

**왜 편향 보정이 필요한가**: `m`과 `v`는 0에서 시작하므로 첫 스텝에서 `m₁=(1-β₁)·gradient=0.1×gradient`처럼 실제 기울기의 1/10 크기로 위축됩니다. `m̂ = m/(1-β₁ᵗ)`로 나누면 t=1일 때 `1-0.9¹=0.1`이라 정확히 원래 크기로 복원되고, t=50 이후로는 `(1-β₁ᵗ)≈1`이라 보정 효과가 자연스럽게 사라집니다. 이 보정이 없으면 학습 초반 수십 스텝이 지나치게 소극적으로 움직입니다.

Adam은 진동(momentum)·파라미터별 스케일(RMSProp)·초반 부진(편향 보정), 이 세 문제를 한 번에 해결하기 때문에 대부분의 상황에서 기본값으로 써도 잘 작동합니다.

## AdamW — 정규화를 옵티마이저 계산에서 떼어내기

SGD에서는 손실에 `(λ/2)w²`를 더하는 L2 정규화와, 매 스텝 `w`를 일정 비율 줄이는 가중치 감쇠(weight decay)가 수학적으로 똑같습니다. 하지만 Adam에서는 다릅니다 — L2 항을 손실에 넣으면 그 항의 기울기도 `√v̂`로 나눠지는 적응형 학습률의 영향을 받아서, 기울기 분산이 큰 파라미터는 정규화가 약해지고 분산이 작은 파라미터는 정규화가 세지는 왜곡이 생깁니다(Loshchilov & Hutter, 2017).

AdamW는 가중치 감쇠를 Adam의 적응형 스텝과 분리합니다.

```
w ← w - lr · m̂ / (√v̂ + ε)     (여기까지는 Adam과 동일)
w ← w - lr · λ · w              (가중치 감쇠는 별도, 적응형 스케일의 영향을 안 받음)
```

BERT·GPT·LLaMA를 포함해 거의 모든 현대 트랜스포머가 AdamW로 학습됩니다. `weight_decay=0.01` 정도가 표준값입니다.

## 아키텍처별 선택 요약

| 아키텍처 | 옵티마이저 | 학습률 | 비고 |
|---|---|---|---|
| Transformer/LLM | AdamW | 1e-4 | weight_decay 0.01~0.1, [[학습률 스케줄\|warmup+cosine]] |
| CNN/ResNet | SGD+Momentum | 0.1 | momentum=0.9 |
| GAN | Adam | 2e-4 | β₁=0.5(비표준, 안정성용) |
| Fine-tuning | AdamW | 1e-5~5e-5 | weight_decay 0.01 |

학습률은 가장 영향이 큰 단일 하이퍼파라미터입니다 — 자세한 스케줄은 [[학습률 스케줄]] 참고. 기울기가 지나치게 커지는 걸 막는 그래디언트 클리핑(`‖gradient‖`가 임계값을 넘으면 비례적으로 축소)도 실무에서 함께 씁니다.
