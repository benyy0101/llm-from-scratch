# 정규화 (드롭아웃·가중치 감쇠)

신경망은 파라미터가 충분히 많으면 데이터를 "이해"하는 대신 통째로 "암기"할 수 있습니다. 실제로 라벨을 완전히 무작위로 섞어놓은 이미지넷 데이터로도 표준 네트워크는 훈련 손실을 거의 0까지 떨어뜨립니다 — 의미 없는 입출력 쌍조차 외워버린다는 뜻입니다(Zhang et al., 2017). GPT-3처럼 파라미터가 1,750억 개인 모델이 정규화 없이 학습됐다면 훈련 데이터를 그대로 재생하는 결과를 냈을 것입니다. 정규화는 이 "암기 유혹"에 부과하는 세금입니다.

과적합은 스펙트럼입니다 — 훈련 정확도와 테스트 정확도의 차이(**generalization gap**)가 벌어질수록 암기가 심해졌다는 신호이고, 정규화의 목표는 이 갭을 줄이는 것입니다.

## 드롭아웃 — 뉴런을 무작위로 꺼서 서로 의존하지 못하게 하기

훈련 중 매 순전파마다 각 뉴런을 확률 p로 꺼버립니다(출력을 0으로). p=0.5면 매번 뉴런의 절반이 사라집니다. 이러면 네트워크는 "특정 뉴런 조합이 항상 켜져 있다"는 가정을 할 수 없어서, 중복되고 서로 대체 가능한 표현을 학습하도록 강제됩니다(공동 적응 방지). 뉴런이 N개면 매 스텝 서로 다른 `2ᴺ`가지 부분 네트워크 중 하나를 훈련하는 셈이라, 결과적으로 거대한 앙상블을 동시에 학습하는 것과 비슷한 효과를 냅니다.

**역스케일 드롭아웃**: 훈련 중에는 `출력 = activation(z) × mask / (1-p)`로 나눠줘서 기댓값을 보정하고, 테스트 때는 아무것도 안 하고 모든 뉴런을 그대로 씁니다(`model.eval()` 빼먹으면 테스트 정확도가 실행마다 들쭉날쭉해지는 흔한 버그가 바로 이 지점입니다).

트랜스포머는 p=0.1 정도로 약하게, 일반 MLP는 p=0.5로 강하게 거는 게 관례입니다 — 트랜스포머는 다른 정규화 장치(대량의 데이터, LayerNorm 등)가 이미 많아서 드롭아웃까지 세게 걸면 오히려 과소적합됩니다.

## 가중치 감쇠(Weight Decay / L2)

```
total_loss = task_loss + (λ/2) Σ wᵢ²
```

이 항의 기울기 `λ·w`가 매 스텝 가중치에서 그대로 빠져나가므로, 결과적으로 가중치가 매 업데이트마다 조금씩 0 쪽으로 수축합니다. 큰 가중치는 입력의 작은 변화에도 출력이 급격히 흔들리는 "날카로운" 함수를 만들기 쉬운데, 가중치를 작게 유지하면 노이즈에 덜 민감한 매끄러운 함수를 선호하게 됩니다. SGD에서는 L2 정규화와 가중치 감쇠가 수학적으로 동일하지만, Adam류 옵티마이저에서는 그렇지 않다는 점은 [[옵티마이저 (SGD·Adam)|AdamW]] 노트에서 다룹니다.

## 배치 정규화(BatchNorm)와 계층 정규화(LayerNorm)

두 방법 모두 "각 층의 출력을 평균 0, 분산 1 근처로 재조정한 다음, 학습 가능한 `γ·x̂+β`로 다시 스케일·이동시킨다"는 같은 골격을 씁니다. 차이는 **통계를 어느 축으로 계산하느냐**입니다.

- **BatchNorm**: 같은 미니배치 안의 여러 샘플에 걸쳐 평균·분산을 계산합니다. 배치 크기가 32 이상은 돼야 통계가 안정적이고, 배치 크기 1이면 사실상 무의미합니다. 훈련 중에는 배치 통계를, 추론 중에는 훈련 동안 누적해둔 이동평균을 씁니다(그래서 훈련/추론 코드 경로가 다릅니다).
- **LayerNorm**: 한 샘플 안에서 특성 차원에 걸쳐 평균·분산을 계산합니다. 다른 샘플과 무관하므로 배치 크기가 1이든 시퀀스 길이가 들쭉날쭉하든 항상 똑같이 동작합니다 — 트랜스포머가 BatchNorm 대신 LayerNorm을 쓰는 이유가 정확히 이것입니다(생성 시점에는 배치 크기가 1인 경우도 흔합니다).

**RMSNorm**은 LayerNorm에서 평균을 빼는 과정(centering)과 이동 파라미터 β를 없애고 `y = γ·x/√(mean(x²))`만 남긴 경량화 버전입니다. 성능은 LayerNorm과 거의 동일하면서 연산이 약 10% 가볍고, LLaMA 계열을 비롯한 최신 LLM 대부분이 LayerNorm에서 RMSNorm으로 옮겨갔습니다.

정규화 층이 왜 학습을 돕는지에 대한 원래 설명("내부 공변량 변화 감소")은 이후 반박됐고, 지금은 손실 지형 자체를 매끄럽게 만들어 더 큰 학습률을 안전하게 쓸 수 있게 해준다는 설명(Santurkar et al., 2018)이 더 유력합니다.

## 데이터 증강과 조기 종료

**데이터 증강**은 모델이 아니라 데이터를 바꿉니다 — 이미지를 무작위로 자르거나 뒤집고, 텍스트는 동의어로 바꾸는 식으로 원본 하나를 여러 변형으로 늘려서 모델이 각 예시를 "정확히 한 번" 외우는 걸 불가능하게 만듭니다. **조기 종료(Early Stopping)**는 가장 간단한 정규화로, 검증 손실이 일정 에포크(patience, 보통 5~20) 동안 개선되지 않으면 그 이전 최적 시점의 가중치로 되돌려 훈련을 멈춥니다.
