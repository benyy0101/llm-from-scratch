# RAG와 리랭킹 MOC

[[RAG]]의 색인 → 검색 → 리랭킹 → 답변 → 평가를 연결한 개념 지도입니다.

## 전체 흐름

```mermaid
flowchart LR
    A["문서 청킹·색인"] --> B["후보 검색 N개"]
    B --> C["결과 병합"] --> D["리랭킹"]
    D --> E["근거 k개 구성"] --> F["LLM 답변"]
```

## 색인과 검색

- [[청킹과 문서 구조]] — 문서를 어떤 단위로 나눠 검색할 것인가
- [[임베딩과 벡터DB]] — 문서를 검색 가능한 표현으로 바꾸고 저장
- [[하이브리드 검색]] — 의미 검색과 키워드 검색의 후보 결합
- [[쿼리 재작성과 확장]] — 질문의 표현을 바꿔 검색 누락 보완
- [[ANN 검색과 검색 재현율]] — 근사 검색 과정에서 발생하는 누락

## 병합과 리랭킹

- [[RRF]] — 여러 검색 목록을 순위 기준으로 병합
- [[리랭킹]] — 후보를 다시 평가해 최종 상위 결과 개선
- [[Bi-Encoder와 Cross-Encoder]] — 검색과 리랭킹의 계산 구조 비교
- [[Late Interaction]] — 토큰별 표현을 저장하고 나중에 비교

## 답변과 평가
