# 체크섬

파일 내용으로부터 계산해낸 짧은 "지문"입니다. SHA-256 같은 해시 함수에 파일을 통째로 넣으면 64자리 문자열이 하나 나오는데, 이게 그 파일만의 고유한 지문 역할을 합니다.

핵심 성질 두 가지입니다.

1. 같은 파일이면 언제 어디서 계산해도 항상 똑같은 문자열이 나옵니다.
2. 파일 내용이 단 1비트만 바뀌어도 지문이 완전히 다른 문자열로 바뀝니다.

## 왜 폐쇄망 반입에 쓰나

파일이 물리적으로 떨어진 두 네트워크 사이를 이동하는 동안 손상되거나(전송 오류), 실수로 다른 버전이 끼워 넣어지거나, 검증 과정에서 조작될 위험이 있습니다. 그래서 반입 전(인터넷망)에 원본 파일의 지문을 미리 뽑아두고, 반입 후(폐쇄망)에 같은 파일의 지문을 다시 뽑아서 비교합니다 — **받은 파일이 보낸 파일 그대로인지**를 확인하는 것입니다.

```bash
# 반입 전: 지문을 뽑아 파일로 저장
sha256sum model.safetensors > CHECKSUMS.sha256

# 반입 후: 저장해둔 지문과 실제로 일치하는지 재검증
sha256sum -c CHECKSUMS.sha256
# model.safetensors: OK   ← 지문이 일치
```

지문이 일치하면 스캔·승인받았던 원본과 바이트 하나까지 완전히 같다는 게 증명되고, 안 일치하면 전송 중 뭔가 바뀐 것이므로 그 파일은 폐기하고 다시 반입해야 합니다.
