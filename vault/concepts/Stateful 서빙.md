# Stateful 서빙

일반 API 서버의 요청은 stateless라 아무 인스턴스에나 붙여도 상관없지만, LLM 서빙은 요청이 시작되면 [[KV 캐시]]라는 수 GB짜리 상태가 그 요청이 끝날 때까지 특정 GPU 메모리에 붙어 있습니다. 이 상태를 다른 GPU로 옮기는 건 비싸거나 아예 안 되는 경우가 많아서, 한 번 배정된 요청은 사실상 그 GPU에 "고정"됩니다. 그래서 LLM 서빙의 로드밸런싱은 "어디로 보낼까"가 아니라 "이 GPU가 이 요청을 받을 메모리 여유가 있는가"를 보는 문제로 바뀝니다.
