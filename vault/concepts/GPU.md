# GPU

원래 화면에 그림을 그리기 위해 만들어진 하드웨어입니다. 화면의 픽셀 수백만 개를 동시에 계산해야 해서, CPU와는 다른 방향으로 설계됐습니다 — CPU가 복잡한 일을 순서대로 잘 처리하는 소수의 유능한 코어를 갖고 있다면, GPU는 아주 단순한 연산(곱하고 더하기)을 동시에 수천 개씩 병렬로 처리하는 훨씬 많은 수의 단순한 코어를 갖고 있습니다.

공교롭게도 신경망의 핵심 연산인 행렬곱은 "같은 단순 연산을 데이터 여러 개에 동시에 적용"하는 일이라서, GPU의 병렬 구조와 정확히 맞아떨어집니다. 그래서 LLM은 CPU가 아니라 GPU 위에서 돌립니다 — [[가중치]]를 이용한 계산 자체가 대량의 병렬 곱셈이기 때문입니다.

GPU 위에는 자체 메모리인 [[VRAM]]이 물리적으로 붙어 있고, 실제 연산은 VRAM보다 훨씬 작고 빠른 온칩 캐시/레지스터에서 일어납니다.
