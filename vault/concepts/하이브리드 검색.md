# 하이브리드 검색

서로 다른 검색 방식의 후보를 결합하는 방법입니다. [[RAG]]에서는 보통 **dense 의미 검색 + sparse 어휘 검색**을 함께 사용해 한쪽에서 놓치는 근거를 보완합니다.

## 검색 단서의 차이

| 방식 | 주로 보는 단서 | 예시 |
|---|---|---|
| Dense | 학습된 표현의 유사도 | ‘물에 빠뜨림’과 ‘침수’ 연결 |
| BM25 | 단어 일치·빈도·희소성·문서 길이 | 제품 코드·조항 번호 찾기 |
| 학습된 sparse | 모델이 만든 어휘별 가중치 | 학습된 중요 어휘로 검색 |

**Sparse와 BM25는 동의어가 아닙니다.** Sparse는 표현 방식이고 BM25는 점수 함수입니다. [[BGE-M3]]의 sparse 출력도 BM25와 동일하지 않습니다.

## 후보 병합

Dense 30개와 BM25 30개가 20개 겹치면 합집합은 40개입니다. 동일 청크를 합친 뒤 [[RRF]] 등의 방식으로 순서를 정합니다. 서로 다른 점수를 그냥 더하면 척도가 다른 문제가 생깁니다.

합집합에는 각 검색의 결과가 포함되지만, 병합 후 상위 N개로 자르면 정답이 다시 빠질 수 있습니다. **최종 후보 수를 맞춘 Recall@N**으로 비교해야 합니다.
