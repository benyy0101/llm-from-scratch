# 행렬곱과 가중치

[[가중치]]가 "곱해지는 계수"라고 했을 때, 실제로 곱하고 더하는 연산이 행렬곱입니다. 입력 벡터 하나와 가중치 행렬 하나를 곱하면 새로운 벡터 하나가 나옵니다.

```
출력[i] = Σⱼ (가중치[i][j] × 입력[j])
```

출력 벡터의 원소 하나(`출력[i]`)는 "입력 벡터의 모든 원소에 각자 다른 계수를 곱해서 전부 더한 값"입니다. 입력이 4096차원이고 출력도 4096차원이면, 가중치 행렬은 4096×4096 ≈ 1,600만 개의 계수를 담고 있고, 출력 원소 하나를 만드는 데 이 중 4096개를 곱하고 더하는 계산이 필요합니다. [[파라미터 수]]에서 세는 "7B"는 결국 이런 행렬들 속 계수 개수를 다 합한 값입니다.

## 왜 이게 "지식"을 담을 수 있는가

행렬곱 자체는 곱하고 더하는 산수일 뿐이라 지식이 없습니다. 지식은 "무엇을 곱할지" 정하는 계수 값(가중치) 쪽에 있습니다. 예를 들어 "강아지"의 벡터가 들어왔을 때 특정 가중치 행렬을 곱하면 "동물", "귀여움", "명사" 같은 의미적 특징이 강조된 벡터가 나오도록, 학습 중에 그 수백만 개 계수가 조금씩 조정됩니다([[가중치]] 노트의 "왜 소수로 저장하나" 참고). 즉 같은 연산(행렬곱)을 서로 다른 계수로 반복하면 서로 다른 변환이 되고, 그 계수를 데이터로부터 배우는 것이 학습입니다.

## LLM 안에서 어디에 쓰이나

[[Transformer]] 한 층을 통과할 때마다 입력 벡터가 여러 개의 가중치 행렬을 거칩니다 — [[Query·Key·Value]]를 만드는 행렬, attention 결과를 다시 변환하는 행렬, 그 뒤 피드포워드 층의 행렬 등. 이 층이 수십~수백 개 쌓여 있고, 층마다 큰 행렬곱이 여러 번 일어나는 것이 추론(inference)의 실체입니다. 맨 처음 텍스트가 이 행렬곱에 들어갈 벡터로 바뀌는 과정은 [[토큰 임베딩 (입력 벡터화)]]에서 다룹니다.

## 관련
- [[가중치]] — 행렬곱에서 곱해지는 계수 자체
- [[토큰 임베딩 (입력 벡터화)]] — 텍스트가 행렬곱에 들어갈 벡터로 바뀌는 과정
- [[Transformer]] — 행렬곱이 반복되는 전체 구조
- [[Query·Key·Value]] — 행렬곱으로 만들어지는 대표적인 중간 벡터
- [[파라미터 수]] — 가중치 행렬들 속 계수 개수의 총합
