# 쿼리 재작성과 확장

사용자 질문을 검색에 맞게 고치거나 여러 표현으로 넓히는 방법입니다. **정답 문서가 색인에 있지만 질문의 표현 때문에 누락될 때** 사용합니다.

## 방식

| 방식 | 하는 일 | 예시 |
|---|---|---|
| 재작성 | 생략된 대상·조건을 드러냄 | ‘그것도 돼?’ → 제품 A의 수리 조건 |
| 확장 | 동의어·대체 표현 추가 | 물에 빠뜨림 → 침수·액체 유입 |
| 다중 질의 | 여러 표현으로 검색해 병합 | 원질문 + 재작성 질문 |
| 질의 분해 | 여러 요구를 나눠 검색 | 보증기간 / 침수 예외 |

제품 코드·날짜·부정 조건은 보존해야 합니다. 원질문도 함께 검색하면 잘못 재작성한 질의 하나에 의존하는 것을 줄일 수 있습니다.

## HyDE

**가상 답변 문서를 생성 → 그 문서를 임베딩 → 실제 문서를 검색**하는 방식입니다. 짧은 질문을 문서 형태의 검색 표현으로 바꿉니다.

가상 문서는 검색에만 사용하며 답변 근거가 아닙니다. 잘못 생성된 내용은 검색 방향도 틀어놓을 수 있습니다.
