# 어텐션 변형 (GQA·MQA 등)

표준 어텐션은 컨텍스트 길이 N에 대해 연산·[[KV 캐시]] 모두 O(N²)/O(N) 규모로 커집니다. 128K 컨텍스트를 쓰는 70B급 모델이면 레이어 하나당 160억 개의 어텐션 항목을 계산해야 할 정도라, 실전에서는 이 비용을 줄이기 위한 여러 변형이 쓰입니다. Query 헤드와 Key·Value 헤드의 개수를 다르게 두는 GQA·MQA·MLA는 [[Multi-Head Attention]] 노트에서 다루고, 여기서는 그 외에 "얼마나 멀리까지 볼지" 자체를 줄이거나 바꾸는 변형들을 다룹니다.

## 짧게 — GQA·MQA·MLA은 헤드 수를 조정하는 변형

Query 헤드 수는 그대로 두고 Key·Value 헤드 수만 줄이는 접근입니다 — 자세한 구조와 캐시 절감 수치는 [[Multi-Head Attention]]을 참고하세요. 여기 나오는 SWA·희소·차등 어텐션과는 다른 축의 최적화입니다: GQA/MQA/MLA는 "헤드를 몇 개나 따로 캐싱할까"를 줄이고, 아래 기법들은 "토큰 하나가 몇 개의 다른 토큰을 봐야 하는가" 자체를 줄입니다. 실제 모델은 이 두 축을 동시에 적용합니다(예: 헤드 수도 줄이고 윈도우도 씌우는 식).

## Sliding Window Attention(SWA) — "가까운 과거만 본다"

각 토큰이 전체 과거가 아니라 자기 앞 W개 토큰까지만 봅니다. 윈도우 밖은 그냥 스코어 행렬에서 `-∞` 처리됩니다. 연산이 `O(N·W)`로 줄어드는 것도 이득이지만, 진짜 핵심은 **KV 캐시가 `O(W)`로 고정된다**는 점입니다 — 대화가 아무리 길어져도 캐시 크기가 더 이상 안 늘어납니다. N=131,072, W=1,024라면 캐시가 128배 줄어드는 셈입니다.

문제는 SWA만 쓰면 장거리 검색(예: 프롬프트 맨 앞에 나온 이름을 맨 끝에서 다시 참고하는 것)이 약해진다는 점입니다. 그래서 실전에서는 SWA 층과 전체 어텐션 층을 섞어 쓰는 방식이 표준이 됐습니다 — Gemma 3는 SWA 층 5개당 전체 어텐션 층 1개 비율(5:1)을 씁니다. 층을 섞으면 SWA 층들이 쌓이면서 유효 수용 범위가 윈도우 크기보다 훨씬 넓어지고, 드문드문 낀 전체 어텐션 층이 정말 먼 곳의 정보를 가끔씩 끌어와 채워주는 구조입니다.

## 희소/블록 어텐션 — "중요한 블록만 골라서 본다"

윈도우처럼 위치를 고정하는 대신, 토큰을 블록 단위로 묶고 그중 중요한 블록만 골라 계산하는 접근입니다.

- **로컬 + 보폭(strided)** — 최근 W개 토큰 + 일정 간격(stride)마다 하나씩 떨어진 과거 토큰들만 봄. 연산이 `O(N·√N)`.
- **Longformer/BigBird** — 로컬 윈도우 + 몇 개의 전역 토큰([CLS] 등, 항상 모두가 보고 봐줌) + 무작위 희소 연결을 섞음. 같은 품질을 유지하면서 컨텍스트를 약 2배로 늘렸다는 결과가 보고됨.
- **네이티브 희소 어텐션(DeepSeek-V3.2)** — 어떤 블록이 지금 토큰에게 중요한지를 아예 학습으로 결정해서, 영향이 적은 블록은 커널 단계에서 건너뜁니다. FlashAttention 커널과도 호환되도록 설계됐습니다.

## Differential Attention — "어텐션 싱크"를 상쇄하기

softmax는 각 행의 가중치 합을 반드시 1로 맞추기 때문에, 정말로 참고할 대상이 마땅치 않은 쿼리도 어딘가에는 가중치를 몰아줘야 합니다. 실제로 관찰되는 현상은 이런 쿼리들이 의미 없이 **첫 번째 토큰**에 가중치를 쏟아붓는 것입니다("attention sink") — 정작 필요한 콘텐츠 검색에 쓰여야 할 어텐션 용량이 낭비되는 셈입니다.

Differential Attention은 Q·K 투영을 두 벌 만들어 어텐션 맵 두 개(A₁, A₂)를 얻은 뒤, `결과 = (A₁ − λ·A₂)·V`처럼 하나에서 다른 하나를 빼는 방식으로 이 문제를 다룹니다. A₁이 실제 콘텐츠에 대한 가중치를, A₂가 싱크로 새는 잡음 성분을 담당하게 학습되면서, 뺄셈을 거치면 싱크로 낭비되던 가중치가 상쇄되고 정말 관련 있는 토큰 쪽으로 재배분됩니다. 보고된 효과는 동일 학습 길이에서 혼란도(perplexity)가 5~10% 낮아지고, 유효 컨텍스트 길이가 1.5~2배 늘어나는 정도입니다.

## 비교

| 변형 | 연산량 | KV 캐시 | 실전 사용 예 |
|---|---|---|---|
| 전체 어텐션 | O(N²) | O(N) | 기본값 |
| SWA(W=1024) | O(N·W) | O(W) | Gemma 2/3, Phi-3 |
| Longformer/BigBird | ~O(N) | 혼합 | 초기 장문 인코더 |
| 네이티브 희소 | 활성 블록만 | O(N) | DeepSeek-V3.2 |
| Differential | O(2N²) | O(2N) | 최신 실험 모델 |
