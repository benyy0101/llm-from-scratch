# HyperCLOVA X

Naver가 공개한 한국어 모델 계열(SEED, 0.6B~33B). 한국어 추론에 특화된 32B "Think" 변형을 포함하며, 라이선스는 모델별로 직접 확인이 필요합니다. Naver Cloud는 이 모델을 [[한국은행 사례|한국은행]]·[[미래에셋 사례|미래에셋]] 같은 폐쇄망 구축에도 제공합니다.
