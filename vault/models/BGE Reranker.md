# BGE Reranker

질문·문서 쌍의 관련성 점수를 내는 BAAI의 모델 계열입니다. 다국어 모델 `BAAI/bge-reranker-v2-m3`는 [[리랭킹]]에 사용하는 예시이며, [[BGE-M3]] 임베딩 모델과는 별도 가중치입니다.

## 입력과 출력

| 모델 | 입력 | 출력 |
|---|---|---|
| BGE-M3 | 문서 또는 질문 | 검색 표현 |
| BGE Reranker | 질문 + 후보 본문 | 관련성 점수 |

점수로 후보를 정렬한 뒤 선택된 근거를 생성 모델에 넘깁니다. 리랭커 자체가 사용자 답변을 쓰는 단계는 아닙니다.

## 점수 해석

원시 점수를 sigmoid로 0~1 범위에 옮길 수 있지만 **0.8이 정답 확률 80%를 뜻하지는 않습니다.** 답변 보류 임계값은 실제 관련·무관 문단으로 검증해야 합니다.

## 배포 시 확인

- 가중치·토크나이저·실행 라이브러리 반입
- 질문과 본문을 합친 길이 및 잘리는 위치
- 후보 수·문단 길이·동시 요청에 따른 지연

이 저장소에는 한국어 사내 문서의 품질·속도·VRAM 실측이 아직 없습니다.

## 관련

- [[리랭킹]] — 모델이 들어가는 파이프라인 단계
- [[Bi-Encoder와 Cross-Encoder]] — 관련성을 계산하는 구조
- [[BGE-M3]] — 이름이 비슷하지만 역할이 다른 모델
- [[RAG 평가]] — 같은 후보로 적용 전후 비교
