# 가상 스위치 포트

[[Hyper-V]]가 소프트웨어로 만들어내는 가상의 네트워크 스위치(허브)입니다. 물리적인 스위치가 여러 컴퓨터의 랜선을 꽂아 서로 통신하게 해주듯이, 가상 스위치는 여러 [[가상머신]]의 가상 NIC을 "포트" 하나씩에 꽂아 서로, 그리고 Windows 호스트와 통신하게 해줍니다.

핵심은 **이 포트 단위로 별도의 방화벽 정책을 걸 수 있다**는 점입니다. 이게 바로 [[Hyper-V 방화벽]]이 존재하는 이유입니다 — 일반 Windows 방화벽은 물리적 네트워크 어댑터 단위로 동작하지만, Hyper-V 방화벽은 이 가상 스위치 포트 단위로 별도 동작합니다. 그래서 물리 어댑터 기준 방화벽 규칙이 전부 허용이어도, 가상 스위치 포트 계층에서 따로 막으면 통신이 안 될 수 있습니다.

실제로 [[WSL2]]를 설치하면 Windows 네트워크 어댑터 목록에 `vEthernet (WSL (Hyper-V firewall))`이라는 이름의 어댑터가 생기는데, 이름 자체가 "이 포트는 Hyper-V 방화벽이 적용되는 가상 스위치 포트다"라는 걸 그대로 말해줍니다.

## 관련
- [[Hyper-V]] — 가상 스위치를 만드는 주체
- [[가상머신]] — 가상 스위치 포트에 연결되는 대상
- [[Hyper-V 방화벽]] — 가상 스위치 포트 단위로 적용되는 별도 방화벽 계층
- [[WSL2]] — `vEthernet (WSL (Hyper-V firewall))` 어댑터로 이 개념을 직접 확인할 수 있는 사례
