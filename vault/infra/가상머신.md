# 가상머신

물리적인 컴퓨터 한 대 안에서, 소프트웨어([[Hyper-V]] 같은 하이퍼바이저)로 흉내 낸 "또 하나의 완전한 컴퓨터"입니다. 자기만의 가상 CPU·메모리·디스크뿐 아니라 **자기만의 가상 네트워크 카드(NIC)**도 갖고 있고, 이 가상 NIC은 [[가상 스위치 포트]]를 통해 실제 네트워크에 연결됩니다. 물리적으로는 케이블 한 줄 안 움직였는데도, 가상머신 입장에서는 진짜 별도의 네트워크 장치가 하나 더 꽂힌 것과 동일하게 취급됩니다.

**[[WSL2]]는 사실상 가상머신입니다.** "리눅스 프로그램을 Windows 안에서 그냥 실행하는 것"처럼 보이지만, 내부적으로는 부팅할 때마다 경량 유틸리티 VM을 새로 띄우고 그 안에서 실제 리눅스 커널이 동작합니다. 그래서 WSL2 안의 프로세스가 Windows 호스트의 서비스(예: `localhost:11434`에 떠 있는 프로그램)에 접근하려면, 같은 컴퓨터 안이라도 **진짜 네트워크 경계를 하나 건너야** 합니다 — 이것이 `127.0.0.1`([[바인드 주소]] 참고)로만 열어둔 서비스에 WSL에서 접근이 안 되는 근본 이유입니다.

## 관련
- [[Hyper-V]] — 가상머신을 만들고 실행하는 하이퍼바이저
- [[가상 스위치 포트]] — 가상머신의 네트워크가 실제 네트워크와 만나는 지점
- [[WSL2]] — "가상머신처럼 안 보이지만 실제로는 가상머신"인 대표 사례
- [[바인드 주소]] — 가상머신이라는 네트워크 경계 때문에 `127.0.0.1` 바인딩이 문제가 되는 이유
