# Hyper-V

Microsoft가 Windows에 내장한 하이퍼바이저(가상화 엔진)입니다. 물리적인 컴퓨터 한 대 위에서 여러 개의 독립된 [[가상머신]]을 동시에 돌릴 수 있게 해주는 저수준 소프트웨어 계층으로, Windows 10/11 Pro 이상에는 기본 탑재돼 있습니다.

중요한 건 사용자가 Hyper-V Manager로 VM을 직접 만든 적이 없어도, 이미 Hyper-V가 몰래 쓰이고 있는 경우가 많다는 점입니다. **[[WSL2]]가 대표적인 예**입니다 — WSL2는 "리눅스 명령어를 Windows에서 흉내 내는" 방식이 아니라, 실제로 Hyper-V 위에 경량 리눅스 [[가상머신]]을 띄우고 그 안에서 진짜 리눅스 커널을 돌립니다. 그래서 WSL2와 Windows 호스트 사이의 통신은 같은 프로세스끼리 메모리를 공유하는 게 아니라, [[가상 스위치 포트]]를 거치는 진짜 네트워크 통신이 되고, 이 경로에는 일반 Windows 방화벽과 별개로 [[Hyper-V 방화벽]]이 적용될 수 있습니다.

## 관련
- [[가상머신]] — Hyper-V가 실행하는 대상
- [[가상 스위치 포트]] — Hyper-V가 VM들의 네트워크를 연결하는 방식
- [[WSL2]] — 사용자가 의식하지 못한 채 Hyper-V를 쓰고 있는 대표 사례
- [[Hyper-V 방화벽]] — Hyper-V가 있기 때문에 존재하는 별도 방화벽 계층
