# 5단계 · 여러 명이 써도 버티는 서빙 엔진으로 교체

[[Ollama]]는 혼자 쓰는 실험엔 충분하지만 동시 사용자가 늘면 처리량이 급격히 떨어집니다. [[vLLM]]으로 교체해 실제 GPU 서버 서빙을 경험하는 단계입니다 (반나절, GPU 필요). 진행 전에 [[Prefill과 Decode]]부터 [[전통 서버 서빙과의 차이]]까지 서빙 이론을 먼저 읽어두면 설정 옵션이 뭘 조절하는지 이해가 훨씬 쉽습니다.

```bash
pip install vllm
vllm serve ./models/qwen2.5-7b-instruct --port 8000
```

여러 팀이 나눠 쓰거나 사용량을 통제해야 한다면 vLLM 앞에 [[LiteLLM]] 같은 게이트웨이를 세우고, 어떤 GPU로 이걸 감당할지는 [[GPU 선택]] 참고.
