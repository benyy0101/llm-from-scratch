# 1단계 · 내 PC에서 첫 로컬 LLM 실행

터미널이 무서우면 [[GPT4All]]로, 이후 단계와 이어가려면 [[Ollama]]로 시작합니다 (30분). 목표는 "인터넷 없이도 모델이 답한다"를 직접 확인하는 것 — [[폐쇄망]] 배포의 가장 작은 축소판입니다.

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5:7b
ollama run qwen2.5:7b
```
