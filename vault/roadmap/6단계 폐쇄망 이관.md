# 6단계 · 인터넷 없는 환경으로 통째로 옮기기

지금까지 만든 스택을 인터넷 되는 스테이징 PC에 재현한 뒤, 그 결과물만 승인된 경로로 [[폐쇄망]]에 반입하는 실전 리허설 (1~2일). [[NVIDIA NIM]]의 공식 에어갭 문서가 이 단계의 참고 모델로 가장 구체적입니다.

```bash
huggingface-cli download Qwen/Qwen2.5-7B-Instruct --local-dir ./staging/models/qwen2.5-7b
pip download -r requirements.txt -d ./staging/wheels
docker save vllm/vllm-openai:latest -o ./staging/vllm-image.tar
```
