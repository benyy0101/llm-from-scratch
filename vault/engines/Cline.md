# Cline

VS Code 확장 형태의 오픈소스 **자율 코딩 에이전트**입니다. 처음엔 "Claude Dev"라는 이름으로 Claude API 전용으로 시작했다가, 지금은 모델 독립적(model-agnostic)으로 확장돼 [[vLLM]]·[[Ollama]] 같은 OpenAI 호환 엔드포인트를 그대로 붙일 수 있습니다.

## [[함수 호출 (Tool Use)|에이전트 루프]]를 오픈소스로 구현한 클라이언트

모델 자체는 "이 도구를 불러줘"라는 구조화된 요청만 낼 뿐이고, 실제로 파일을 읽고 셸을 실행하고 그 결과를 다시 모델에 넘기는 오케스트레이션은 Cline 같은 애플리케이션의 역할입니다. Cline은 파일 다중 수정·터미널 명령 실행·git diff 조회 등을 도구로 내장하고 있어, 별도 [[MCP (Model Context Protocol)|MCP]] 서버 없이도 기본적인 코딩 작업 루프가 바로 동작합니다.

## Continue.dev와의 차이

| | Cline | [[Continue.dev]] |
|---|---|---|
| 성격 | 자율 에이전트 중심 — 계획·다중 파일 수정·명령 실행까지 스스로 진행 | 자동완성 + 채팅 중심, 에이전트 모드는 이후에 추가된 편 |
| 승인 흐름 | 액션마다 승인받는 UI가 촘촘함 | 상대적으로 느슨 |
| 모델 요구사항 | 자율성이 안정적으로 동작하려면 대략 **22B급 이상** 모델 필요 | 작은 모델로도 자동완성 정도는 무난 |

승인 절차가 중요한 조직(금융권 등)에는 Cline의 촘촘한 승인 UI가 유리한 경우가 많습니다.

## 서브에이전트 — 제한적인 멀티에이전트 지원

v3.58부터 **Native Subagents**를 지원합니다. 메인 에이전트가 명시적으로 요청하면 병렬 리서치용 서브에이전트를 띄워 코드베이스 탐색·cross-cutting 이슈 추적을 병렬로 시키고 결과 보고서만 돌려받을 수 있습니다. 단, 이 서브에이전트는 **읽기 전용**이라 파일 쓰기·파괴적 명령 실행·MCP 서버 접근은 못 합니다. [[Hermes Agent]]의 Bot Mode(쓰기 권한까지 있는 여러 에이전트가 서로 메시지를 주고받는 구조)만큼 완전한 [[멀티턴과 멀티에이전트 (구분)|멀티에이전트]]는 아니고, "메인 에이전트 한 명 + 읽기 전용 정찰병 여러 명"에 가까운 절반짜리 구조입니다.

## 폐쇄망 설치

VS Code 마켓플레이스도 인터넷 서비스라 폐쇄망에서는 직접 열리지 않습니다. [[Continue.dev]]와 마찬가지로 인터넷 되는 곳에서 `.vsix` 파일을 받아 [[체크섬]] 검증 후 반입하고, 오프라인으로 설치합니다.

```bash
code --install-extension ./import/extensions/cline.vsix
```
