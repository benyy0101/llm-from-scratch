# Presidio

Microsoft가 만든 오픈소스 개인식별정보(PII) 탐지·마스킹 도구입니다. Analyzer(탐지)와 Anonymizer(마스킹) 두 컴포넌트로 나뉘고, 둘 다 컨테이너로 자체 호스팅할 수 있어 외부 API 호출 없이 완전 [[폐쇄망]]에서도 쓸 수 있습니다. [[LiteLLM]]은 이 둘을 "presidio" 가드레일로 바로 연동할 수 있게 지원합니다.

기본 제공되는 개체명 인식(NER) 모델은 영어권 이름·주소 패턴 위주로 학습돼 있어, 한국어 인명·주소 인식률은 낮은 편입니다. 반면 전화번호·계좌번호·주민등록번호처럼 **형식이 뚜렷한 정보**는 정규식 기반 커스텀 인식기(Pattern Recognizer)를 추가해 언어에 상관없이 안정적으로 잡을 수 있습니다. 실무에서는 완벽한 개체명 인식을 목표로 하기보다, 이렇게 "형식이 뚜렷한 정보부터 확실히 막는다"는 현실적인 범위를 먼저 잡는 경우가 많습니다.

## 관련
- [[PII 마스킹]] — Presidio가 구현하는 상위 개념
- [[LiteLLM]] — Presidio를 가드레일로 연동하는 게이트웨이
