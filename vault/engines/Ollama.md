# Ollama

개인 실험용으로 가장 접근성이 좋은 로컬 LLM 실행 도구. [[llama.cpp]]를 내부 엔진으로 쓰며 [[GGUF]] 포맷을 다룹니다. 추론 자체는 완전 오프라인이지만, 백그라운드로 버전 체크 요청을 보내는 숨은 네트워크 호출이 있어 [[폐쇄망]] 환경에서는 방화벽에서 별도로 차단해야 합니다. 동시 사용자가 늘면 처리량이 급격히 떨어져 프로덕션에는 약하고, [[Continuous Batching]] 같은 최적화가 없어 [[vLLM]]으로 넘어가는 게 일반적입니다.
