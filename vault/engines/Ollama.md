# Ollama

개인 실험용으로 가장 접근성이 좋은 로컬 LLM 실행 도구. [[llama.cpp]]를 내부 엔진으로 쓰며 [[GGUF]] 포맷을 다룹니다. 추론 자체는 완전 오프라인이지만, 백그라운드로 버전 체크 요청을 보내는 숨은 네트워크 호출이 있어 [[폐쇄망]] 환경에서는 방화벽에서 별도로 차단해야 합니다. 동시 사용자가 늘면 처리량이 급격히 떨어져 프로덕션에는 약하고, [[Continuous Batching]] 같은 최적화가 없어 [[vLLM]]으로 넘어가는 게 일반적입니다.

## 관련
- [[llama.cpp]] — Ollama의 내부 엔진
- [[GGUF]] — Ollama가 다루는 포맷
- [[vLLM]] — 프로덕션 전환 시 옮겨가는 대안
- [[1단계 첫 로컬 실행]] · [[2단계 채팅 UI]] · [[3단계 모델·양자화 비교]] — Ollama로 진행하는 로드맵 단계
- [[모델과 엔진]] — Ollama는 모델이 아니라 엔진(소프트웨어)이라는 구분. 백그라운드 버전 체크는 그 안에서 돌아가는 모델이 아니라 Ollama라는 프로그램 자체의 습성
- [[바인드 주소]] — 기본값(`127.0.0.1`)이 [[WSL2]] 같은 가상 환경에서 접근을 막는 원인이 되는, 또 다른 방향의 네트워크 이슈
