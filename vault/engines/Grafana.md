# Grafana

[[Prometheus]]·[[Loki]] 같은 여러 데이터소스를 하나의 대시보드로 시각화하는 오픈소스 도구입니다. EP13에서 "계층별 대시보드"라고 표현한 게 실제로는 서빙([[vLLM]])·게이트웨이([[LiteLLM]])·접근([[Open WebUI]]) 계층마다 별도 대시보드를 만들어둔 것이고, 장애가 나면 어느 계층 대시보드부터 열지가 곧 문제 해결 순서를 정합니다.

## 폐쇄망에서 걸리는 지점

Grafana의 강점 중 하나가 공식 대시보드 갤러리(grafana.com)에서 남이 만든 대시보드를 그대로 가져다 쓰는 것과, 플러그인 마켓플레이스에서 데이터소스 플러그인을 추가하는 건데, 둘 다 인터넷 접속이 전제입니다. [[폐쇄망]]에서는 필요한 대시보드 JSON을 인터넷망에서 미리 export해두고 [[체크섬]] 검증 후 반입해야 하며, 플러그인도 마찬가지로 사전에 내려받아 오프라인 설치해야 합니다.

Grafana 자체에 알람 규칙을 거는 기능(Grafana Alerting)도 있어서, 규모가 작은 구성에서는 [[Alertmanager]]를 따로 두지 않고 이 기능만으로 알람까지 처리하는 경우도 있습니다. 다만 Prometheus의 알람 룰과 라우팅을 더 세밀하게 통제하고 싶다면 Alertmanager를 별도로 두는 쪽이 표준적입니다.

## 관련
- [[관측성]] — 세 기둥(메트릭·로그·트레이스)을 한 화면에서 상관관계로 보여주는 시각화 계층

- [[분산 트레이싱]] — Grafana Tempo를 쓰면 같은 벤더 스택으로 트레이스까지 통합 가능
