# Open WebUI

[[Ollama]] 위에 얹는 ChatGPT 스타일 웹 채팅 UI. 여러 모델 전환, 대화 기록, 문서 업로드 RAG 기능을 제공하며 Docker로 간단히 띄울 수 있습니다. 100% 로컬로 동작해 [[폐쇄망]] 환경의 "사내용 ChatGPT" 최소 형태로 적합합니다.

## 관련
- [[Ollama]] — Open WebUI가 연결되는 백엔드
- [[RAG]] — Open WebUI에 내장된 문서 질의응답 기능
- [[2단계 채팅 UI]] — 이 도구를 실습하는 로드맵 단계
